# Big Data Processing Using Databricks

M.Sc Computer Science Project under the guidance of Dr. Saloni Fathima.

## Overview
Big Data refers to large volumes of data that cannot be processed efficiently using traditional systems. This project demonstrates how Databricks, a cloud-based unified analytics platform built on Apache Spark, efficiently handles big data workloads.

## Technologies Used
- Python Programming Language
- Databricks Platform
- Apache Spark
- Delta Lake

## What We Did
- Ingested large structured & unstructured datasets into Databricks
- Performed data cleaning, transformation & aggregation using Spark-based transformations
- Used Delta Lake to ensure data reliability, consistency & fault tolerance
- Demonstrated improved performance compared to traditional systems with parallel execution & auto-scaling
- Supports both batch and real-time data processing
